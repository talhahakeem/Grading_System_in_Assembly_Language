# Grading_System_Assembly

Welcome to the **Grading System in Assembly Language** repository!  
This project is developed in **Assembly Language** to calculate and display student grades based on marks using low-level programming concepts.

## 📚 Features
- Input student marks and calculate grades.
- Uses conditional statements and arithmetic operations in Assembly.
- Displays grade output in console.
- Helps understand low-level programming, registers, and memory management.
- Console-based application, simple and educational.

## 📝 Contents
- **grading.asm** – Main Assembly program for calculating grades.
- **README.md** – Project documentation.
